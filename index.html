Настройки API

Токены хранятся только в localStorage этого браузера и отправляются только на указанный API-адрес. Сайт статический — на сервере ничего не сохраняется. Не используйте эту страницу на чужом компьютере.

Получить user-key автоматически

Внимание: у Didox жёсткая защита от перебора — 3 неверные попытки в минуту блокируют вход на 10 минут, 25 — навсегда.

Пароль хранится в localStorage браузера в открытом виде. Включайте только на своём личном компьютере. Если автовход получит отказ (неверный пароль, блокировка), пароль сразу удаляется, чтобы не попасть под блокировку.

Нужно установленное и запущенное приложение E-IMZO (e-imzo.uz). Пароль ключа вводится в окне E-IMZO — сайт его не видит.

API-ключ E-IMZO для этого сайта

E-IMZO работает только с сайтами, для домена которых выдан API-ключ. Для localhost ключ встроен. Для этого домена ключ нужно получить у разработчиков E-IMZO (e-imzo.uz) и вставить сюда.
